Alur Data (MVC)

Data karakter dibuat dan dikelola di layer Model, yaitu CharacterManager yang menyimpan ArrayList<Character>. Main.java bertindak sebagai titik awal: ia membuat data lalu menyerahkan salinan daftar ke MainWindow melalui constructor. MainWindow sebagai View hanya menampilkan data, dengan membuat JLabel secara dinamis lewat loop dan menghitung statistik dari daftar yang diterimanya. Karena View tidak membuat data sendiri, perubahan data cukup dilakukan di Main tanpa mengubah kode tampilan.
